# 📋 服务器注册指南

> 欢迎来到梦之韵生存服务器！请按照以下流程完成注册。

## 注册步骤

1. **进入服务器** — 使用 Minecraft 客户端连接服务器地址
2. **设置密码** — 首次进入后输入 `/register <密码>` 完成注册
3. **登录验证** — 每次进入服务器需要输入 `/login <密码>`

## 注意事项

- 密码请设置为 **8 位以上**，包含字母和数字
- 请牢记密码，忘记密码需联系管理员重置
- 不要将密码告诉他人

## 常用命令

| 命令 | 说明 |
| :--- | :--- |
| `/register <密码>` | 注册账号 |
| `/login <密码>` | 登录服务器 |
| `/changepassword <旧密码> <新密码>` | 修改密码 |

> 💡 注册完成后请务必阅读 [服务器管理条例](/posts/mc/rules)！
