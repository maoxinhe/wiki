# 📜 【梦之韵生存服务器】注册说明

> 本指南旨在帮助首次加入服务器的新玩家顺利完成账号的注册与登录。

</div>

### ⚙️ 服务器基础信息
- **客户端版本**：请使用国际版 Java `1.21.11` 客户端加入服务器。
- **特殊说明**：本服务器支持使用**中文名**作为游戏角色昵称。

### ⌨️ 核心指令速览
| 指令 | 功能说明 |
| :--- | :--- |
| `/captcha <验证码>` | 通过人机验证码 |
| `/reg <密码> <密码>` | 注册账号（需输入两次相同密码） |
| `/login <密码>` | 登录账号 |

---

📌 **详细操作步骤请见下方说明**

## 一、通过验证码

加入服务器后，你会看到如下画面：
*图1：验证码认证提示*

**第一步：切换输入法**
请确保已切换至**英文输入法**（通常按下 `Shift` 键即可切换）。

**第二步：打开聊天框**
按下 `T` 键打开聊天框。
> ⚠️ **注意**：如果未切换至英文输入法，可能无法正常呼出聊天框。
打开聊天框后，即可看到验证码的完整信息

**第三步：输入验证码指令**
按照聊天框中显示的完整信息，输入指令：`/captcha xxxxxx`
> 💡 **提示**：请将 `xxxxxx` 替换为你实际看到的验证码，注意斜杠 `/captcha` 和 `验证码` 之间有一个空格

输入完成后，按下回车键（`Enter`）即可完成验证。

---

## 二、注册账号

通过验证码后即可开始注册，**只有完成注册后才能正常游玩**。

**第一步：打开聊天框**
同上一步，按下 `T` 键打开聊天框。

**第二步：输入注册指令**
输入注册命令：`/reg <你的密码> <你的密码>`

> 💡 **示例**：如果你想设置密码为 `abc123`，则输入 `/reg abc123 abc123`
> 1. 请注意指令间的空格。
> 2. 两次输入的密码**必须完全相同**。

**⚠️ 密码安全须知：**
- 为了你的账号安全，**不推荐**设置过于简单的密码（如纯数字或常用单词）。
- 请**务必牢记**你的密码，否则日后将无法登录账号！
- 若不慎忘记密码，只能联系管理员进行重置。

---

## 三、登录账号

首次注册完成后，系统会自动为你登录。但日后再次进入服务器时，需要手动登录账号。

**操作步骤：**
1. 按下 `T` 键打开聊天框。
2. 输入登录指令：`/login <你的密码>`（注意空格）。
3. 按下回车键（`Enter`）即可成功进入游戏！
