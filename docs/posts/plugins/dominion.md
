# 🏰 Dominion 领地插件使用指南

> Dominion 是一款功能强大的领地保护插件，帮助你保护自己的基地和财产。

## 基础命令

| 命令 | 说明 |
| :--- | :--- |
| `/dom claim` | 圈地，站在区域内执行 |
| `/dom info` | 查看当前位置领地信息 |
| `/dom add <玩家>` | 添加成员到领地 |
| `/dom remove <玩家>` | 移除领地成员 |
| `/dom delete` | 删除当前领地 |

## 权限设置

领地支持细粒度的权限控制：

- **build** — 放置/破坏方块
- **chest** — 打开容器
- **interact** — 与方块交互（按钮、门等）
- **pvp** — 是否允许 PVP

## 注意事项

- 圈地需要消耗金币，面积越大消耗越多
- 领地之间不能重叠
- 定期备份领地数据，防止意外丢失

> 💡 更多高级用法请参考 [Dominion 官方文档](https://github.com/Acrobot/Dominion)。
